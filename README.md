# 🧠 sasi-practice

A collection of Java solutions to Data Structures & Algorithms problems, organized by topic. Problems span LeetCode-style challenges, interview prep (Agoda-tagged), and classic DSA patterns.

---

## 📁 Project Structure

```
src/
├── agoda/              # Interview-specific problems
├── arrays/             # Array & matrix problems
├── backtracking/       # Backtracking problems
├── dp/                 # Dynamic programming
├── slidingwidow/       # Sliding window technique
├── sorting/            # Sorting algorithms
├── stack/              # Stack-based problems
├── tree/               # Binary tree problems
└── twopointers/        # Two pointer technique
```

## 🛠️ Setup

**Requirements:** Java 11+, IntelliJ IDEA (recommended)

```bash
# Clone the repo
git clone https://github.com/sasidhar17/sasi-practice.git
cd sasi-practice

# Open in IntelliJ IDEA
# File → Open → select the sasi-practice folder
# Mark src/ as Sources Root
```

Each file is standalone — just run the `main` method (if present) or write a test directly.
