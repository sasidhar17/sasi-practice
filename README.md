# 🧠 sasi-practice

A personal Java repository for practising Data Structures & Algorithms — covering LeetCode-style problems, interview prep, and classic DSA patterns, organised by topic.

---

## 📁 Project Structure

```
src/
├── agoda/              # Interview-specific problems
├── arrays/             # Array & matrix problems
├── backtracking/       # Backtracking problems
├── dp/                 # Dynamic programming
├── graphs/             # Graph traversal problems
├── linkedlist/         # Linked list problems
├── slidingwidow/       # Sliding window technique
├── sorting/            # Sorting algorithms
├── stack/              # Stack-based problems
├── tree/               # Binary tree problems
└── twopointers/        # Two pointer technique
```

> New topics get their own package as problems are added.

---

## 🗂️ Topics Covered

| Topic | Key Techniques |
|---|---|
| **Arrays & Matrix** | Prefix sums, in-place ops, DFS/BFS on grids |
| **Two Pointers** | Opposite ends, fast/slow pointers |
| **Sliding Window** | Fixed & variable size windows, frequency maps |
| **Stack** | Monotonic stack, parentheses matching |
| **Trees** | DFS, BFS, BST operations, recursion |
| **Dynamic Programming** | Bottom-up tabulation, memoisation |
| **Backtracking** | Subsets, permutations, combinations |
| **Sorting** | Comparison-based and linear sorts |
| **Graphs** | BFS, DFS, connected components |
| **Linked List** | In-place reversal, two pointers |
| **Interview Prep** | Mixed problems from Agoda & similar interviews |

## 🛠️ Setup

**Requirements:** Java 11+, IntelliJ IDEA (recommended)

```bash
# Clone the repo
git clone https://github.com/sasidhar17/sasi-practice.git
cd sasi-practice

# Open in IntelliJ IDEA
# File → Open → select the sasi-practice folder
# Mark src/ as Sources Root
```

Each file is standalone — run the `main` method directly or add a quick test alongside it.
